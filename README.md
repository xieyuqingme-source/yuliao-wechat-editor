# 雨聊公众号排版

一个在本机运行的中文公众号排版工具：导入 Markdown 和本地图片，编辑正文、预览阅读效果，再复制富文本或导出含图片的 HTML。为公众号「谢雨聊」的写作流程制作，也可用于其他中文文章。

不需要 npm 安装。程序和 Markdown 渲染依赖均随仓库提供；文章和图片由浏览器处理，原文件不会被写回。

## 功能

- 导入、拖入 UTF-8 Markdown，或直接粘贴正文和实际图片。
- 解析 Obsidian `![[图片]]`、路径及尺寸，以及标准 Markdown 本地图片；支持中文、空格、相对路径。缺图、重名、不可读取图片均给出提示。
- 三种中文排版主题，常用 Markdown 组件，撤销与重做；可控清理开头 YAML 属性。
- 编辑器与实时预览；手机 390 px、平板 768 px、电脑 1000 px 阅读宽度自动缩放以完整显示，双向滚动按进度近似同步。预览缩放不进入复制或导出。
- 正文字号、行距、主题色可调整；相关文章和参考资料字号略小。参考区的多余行首空白可局部清理、撤销。
- 主动导入历史文章目录，人工选择、排序和编辑推荐标题；可重新选择目录更新索引，推荐区只输出选中的标题。
- 发布前排版提示、富文本复制、含图片 HTML 导出、完整草稿导入导出，以及浏览器本地自动保存和最近 8 份备份。

这里的发布前检查只提醒图片、占位文字、重复推荐和长标题等排版问题，不是内容审核，也不保证微信最终效果。

## Windows 启动

1. 从本仓库下载 ZIP，**完整解压**到一个文件夹；保留 `vendor`、`samples` 和其他随附文件。
2. 安装 [Node.js](https://nodejs.org/)，推荐 **Node.js 24 LTS**，也可使用 22 LTS。安装后重新打开终端，运行 `node --version` 确认可用。版本支持状态以 [Node.js 官方发布表](https://nodejs.org/en/about/previous-releases) 为准。
3. 双击 [启动谢雨聊.cmd](启动谢雨聊.cmd)，保持出现的启动窗口打开。
4. 在 Edge 或 Chrome 中手动打开 **http://127.0.0.1:8765**。
5. 用完后关闭启动窗口，或在该窗口按 `Ctrl+C`。

不需要执行 `npm install`。不要直接打开 `index.html`；请使用本机 HTTP 地址，以便模块、草稿和剪贴板功能正常工作。

升级前导出需要保留的完整草稿。替换程序文件后，关闭旧启动窗口、重新启动，再刷新网页；仅刷新页面不会更新旧服务的文件清单。程序不会自动清除浏览器草稿。

端口占用时，先关闭旧服务，或在项目文件夹的 PowerShell 中运行：

```powershell
$env:XIEYULIAO_PORT = '8766'
node .\server.mjs
```

随后访问 `http://127.0.0.1:8766`。不同端口、主机名和浏览器的草稿存储相互独立，日常使用请固定一个地址。

macOS / Linux 可在项目文件夹运行 `node server.mjs`，然后手动访问同一地址；此入口使用 Node 标准库，但这些系统尚未完成实际运行验收。

## 先用合成样例试一次

1. 点击 **导入 Markdown**，选择 `samples/vault/文章/正常示例.md`。
2. 点击 **选择／替换附件目录**，选择 `samples/vault`；按浏览器提示确认选择。
3. 在 **文章在所选目录中的相对路径** 中填写 `文章/正常示例.md`，不要加 `vault/` 前缀。
4. 检查图片顺序，切换主题和阅读宽度，再尝试复制富文本、导出 HTML、导出和重新导入完整草稿。

样例文章和图片均为合成内容。[样例说明](samples/使用说明.md) 包含正常场景、缺图和重名场景，以及待执行的真实浏览器检查步骤；[完整使用说明](docs/USAGE.md) 介绍自己的文章、推荐列表和参考资料如何处理。

## 隐私与安全边界

- 页面只接收你主动选择、拖入或粘贴的文件；不会根据本机路径扫描磁盘。Node 服务只提供固定清单中的程序静态文件，监听 `127.0.0.1`，没有文章上传或文件读取接口。
- 附件目录先建立文件名索引，只读取正文实际匹配的图片内容。历史文章在你主动选择后读取以提取标题和内容标识，持久记录不保留历史正文。
- 应用不上传图片，不调用 AI、图床或公众号后台，不下载远程图片。SVG 和文章中的原始 HTML 不作为可执行内容渲染。
- 自动草稿留在当前浏览器的 IndexedDB 中。无痕模式、清理浏览器数据、切换地址或存储容量不足，都可能使草稿不可用；重要文章请另外导出完整草稿。
- **完整草稿 JSON 是私密备份**：含当前文章、已读取／粘贴图片、文件名、相对路径和本地来源索引。导出的 HTML 也含文章和嵌入图片。分享前自行检查，不要把自己的草稿、文章、图片、导出文件或运行日志提交到公开仓库。

本仓库只提供合成样例。忽略规则是辅助措施，无法识别所有个人文件；贡献时仍需检查暂存文件与提交历史。

## 兼容性与限制

桌面 Edge / Chrome 是建议使用的浏览器。目录选择、剪贴板、图片解码和本地存储依赖浏览器能力与权限；其他浏览器及移动端未完成兼容性验收。某些目录选择器可能要求确认整个目录，选择前请核对范围。

新正文上限 5 MiB（UTF-8），单张图片 20 MiB，已读取图片的内嵌数据总预算 64 MiB。超限会提示并保留原内容；旧格式草稿仍可导入备份及删减，超正文排版上限时暂停预览和富文本输出。详细限制见 [使用说明](docs/USAGE.md)。

富文本复制提供 HTML 与纯文本，并在支持的浏览器中使用剪贴板 API。复制需要由点击触发，并受安全上下文及权限限制；失败时可导出 HTML 后手动复制。[Clipboard API 说明](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/write)

**微信公众号可能删除 Base64 图片或调整 HTML 样式。** 粘贴后的图片保留、后台保存、实际发布和手机预览都需自行检查；本地预览不是微信验收结果。预览的三种宽度只是阅读空间模拟，滚动同步也不保证逐段精确对应。

自动化测试覆盖合成文件、状态、渲染结果、布局计算和本机服务；模拟 DOM 与剪贴板测试不等于真实浏览器视觉、系统剪贴板、IndexedDB 持久化或微信后台验收。具体记录见 [VERIFICATION.md](VERIFICATION.md)。

## 开发与验证

使用受支持的 Node.js LTS，在项目根目录执行：

```sh
node --test
node --check app.mjs
node --check core.mjs
node --check server.mjs
node build.mjs
```

测试无需 npm 或第三方安装；本机 HTTP 测试需要允许回环连接。`build.mjs` 生成 `dist/` 作为本地运行分发目录，不会发布网站。静态网页可行性和后续 GitHub Pages 方案见 [docs/PAGES.md](docs/PAGES.md)，当前没有启用 Pages，也不会修改个人网站。

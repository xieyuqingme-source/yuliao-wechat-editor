# 在一篇文章里，留一点呼吸

这是「谢雨聊」的合成样例。它用来检查排版工具对**中文、空格路径和本地图片**的处理，不包含个人笔记。

## 一、同位图片

下面的图片与这篇 Markdown 放在同一个目录。图片应保持在这一段和下一标题之间。

## 二、库内路径与尺寸

这里使用 Obsidian 的库内路径，并指定 `320x180`。图片的源文件不会因为预览尺寸改变而被修改。

## 五、段落之外

- 一个容易读懂的标题。
- 一段紧贴主题的正文。
- 一张放在正确位置的图片。

1. 导入文章。
2. 选择附件目录。
3. 检查并导出。

| 操作 | 目的 |
| --- | --- |
| 切换主题 | 检查三种样式 |
| 导出草稿 | 保存可继续编辑的正文和图片 |

`行内代码` 与下面的代码块也需要保持可读。

```text
只在本机排版
不改动原稿
```

这篇文章到此结束。最后一段用于确认排版不会误删正文。

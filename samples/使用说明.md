# 合成样例使用说明

这些文章和 PNG 图片仅为测试生成，与真实 Obsidian 文章无关。每次只导入一篇文章，附件目录统一选择 `samples/vault`。

## 正常场景

导入 `vault/文章/正常示例.md`，填写文章相对路径 `文章/正常示例.md`。

| 正文顺序 | 写法 / 场景 | 应匹配文件 | 预期 |
| --- | --- | --- | --- |
| 1 | `![[同位 图片.png]]` | `文章/同位 图片.png` | 出现在「一、同位图片」段落后 |
| 2 | `![[附件/中文 空格图片.png\|320x180]]` | `附件/中文 空格图片.png` | 展示图片，带 320 × 180 尺寸约束 |
| 3 | 标准 Markdown `../附件/标准 图.png`，用尖括号包裹路径 | `附件/标准 图.png` | 中文与空格能匹配 |
| 4 | 标准 Markdown `../附件/中文%20空格图片.png` | `附件/中文 空格图片.png` | 编码空格与相对路径能匹配 |
| 5 | `![[附件/宽图.png\|300]]` | `附件/宽图.png` | 展示图片，带 300 像素宽度约束 |

文章开头有 YAML 属性。默认清理开头属性时应从预览中移除属性块；取消勾选后应恢复。编辑器文本和原 `.md` 保持可见且不被写回。正文中的 `---` 为测试分隔线，不能作为开头属性一起删除。

重复选取附件目录请用 **选择／替换附件目录**，正常文章不应因此新增图片或产生重复记录。复制富文本、导出 HTML 和完整草稿后，再导入完整草稿，检查图片顺序、正文、主题和属性设置保留。

## 异常场景

导入 `vault/文章/异常示例.md`，填写文章相对路径 `文章/异常示例.md`。

| 场景 | 引用 | 应出现的结果 |
| --- | --- | --- |
| 缺图 | `![[没有这张图.png]]` | 缺图提示和原位置占位 |
| 文件名重名 | `![[同名.png]]` | 列出重名候选，不能自动选定 |
| 明确目录消除重名 | `![[附件/同名.png]]` | 匹配青绿色合成图 |
| 明确目录消除重名 | `![[其他/同名.png]]` | 匹配暖橙色合成图 |
| 远程图片 | `https://example.invalid/private-image.png` | 阻止下载并提示，不能发起网络读取 |
| 越界引用 | `../../范围外.png` | 无法匹配所选目录外文件，并提示 |

页面的提示用语可能随实现调整；关键是缺图、歧义和不支持的图片没有被悄悄替换或上传。完成后可重新导入正常示例，确认异常提示会相应清除。

## 无需个人文章的手动检查

1. 从本机文件打开任一合成 PNG，用系统截图或复制图片功能将真实像素放入剪贴板；在正文中间按 `Ctrl+V`，确认插入当前位置。
2. 切换三个主题，调整字号、行距、主题色，观察预览更新与字数变化。切换 390、768、1000 px 阅读宽度并调整窗口宽度，检查文章是否完整显示、状态是否显示缩放比例。
3. 点击 **复制公众号富文本**，根据复制结果提示，在一个你自行打开的富文本编辑器粘贴。确认段落、图片和样式是否进入剪贴板。
4. 导出含图片 HTML，在断网时手动打开该导出文件，确认图片依然显示。
5. 导出完整草稿，关闭并重启页面后检查自动恢复；再导入导出的草稿，检查已读取和粘贴图片。
6. 检查备份菜单的恢复与清除。清除之前先保存需要的完整草稿；完整草稿含文章、图片及相对路径，只用于本机备份，不要提交到公开仓库。
7. 打开 `相关文章示例.md`，点击 **选择历史文章目录** 并选择 `samples/history`。目录入口只纳入符合规则的 Markdown；TXT 用 **单独导入 .md / .txt**。勾选、排序、取消和编辑显示标题，检查正文推荐列表不会重复叠加。
8. 在该文章的粗体「参考资料 / References」区域，检查字号较正文略小、有序编号保留。点击 **清理参考资料行首空白**，核对只改该区域，英文词间空格与链接保留，再点击 **撤销** 恢复。
9. 分别滚动编辑器与预览，加载图片、切换宽度，再用短文章检查无可滚动空间的情况。同步是阅读进度近似对应，可关闭单独滚动。
10. 点击 **发布前排版检查**，确认提示可定位且不阻止复制或导出。40 字标题阈值只是排版建议。

以上是待执行的真实 UI 检查步骤，不表示已经通过。自动化测试使用合成输入及模拟环境，不能代替实际浏览器视觉、系统剪贴板和持久化验收。微信公众号后台保存、Base64 图片保留和实际手机预览仍需手动验证。

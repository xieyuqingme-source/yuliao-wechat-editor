# 使用说明

## 导入自己的文章和图片

点击 **导入 Markdown** 选择 UTF-8 `.md` / `.markdown`，也可拖入文件，或直接在编辑区粘贴正文。导入替换当前文章时请按页面提示处理未保存内容。

再选择文章所在仓库或较小的附件目录。浏览器只提供你选中的文件与相对路径；页面不会根据输入的磁盘路径读取其他位置，也不会写回原文件。附件目录首先建立文件名索引，仅读取匹配的图片内容。

填写 **文章在所选目录中的相对路径**：例如选择仓库根目录，而文章在其 `文章` 子目录中，则填写 `文章/我的文章.md`。文章从单独文件入口导入时，浏览器通常不能提供所在目录，须自行核对这一字段。

支持的写法：

```markdown
![[照片.png]]
![[附件/中文 空格图片.png|320]]
![[附件/中文 空格图片.png|320x180]]
![说明](../附件/中文%20空格图片.png)
![说明](<../附件/中文 空格图片.png>)
```

标准 Markdown 相对路径按文章目录解析。Obsidian 带目录引用先尝试所选目录中的精确路径，再尝试文章相对路径；仅有文件名时必须在所选范围内唯一匹配。重名不会随意选取，应补充目录或缩小所选范围。引用所选范围之外的文件不能被读取。

支持 PNG、JPEG、GIF、WebP、BMP、AVIF；能否最终显示仍取决于浏览器解码。远程图片不下载，SVG 不渲染。图片尺寸写法只约束展示宽高，保留原图比例；无效尺寸不会作为样式注入。

在编辑区按 `Ctrl+V` 可粘贴剪贴板中的**真实图片文件**，或使用 **添加图片文件**、拖入图片。图片会插入当前光标处，并成为本地草稿的一部分。复制图片网址或磁盘路径不等同于粘贴图片。

缺图、重名和读取失败会出现在 **图片与排版提示** 中，并在原引用位置保留提示。重复选择同一附件目录时，用 **选择／替换附件目录**；需要其他附件时用 **追加附件目录**。

新输入的正文最多 5 MiB（按 UTF-8 字节计），单张图片最多 20 MiB。已读取图片的内嵌数据总预算为 64 MiB；Base64 数据通常大于原图片文件，不能只把文件大小相加。超预算或本批读取失败时，不保留部分新增图片，原图片保留；请减小图片或分批核对。附件文件索引最多 10 万项。较大的旧格式草稿仍可备份和删减，超过新正文排版上限时暂停排版，避免以旧预览误导复制或导出。

## 编辑与排版

编辑器保留普通 Markdown。工具栏提供标题、引用、重点提示、分隔线、图片说明和参考资料等组件，选中文字后点击可包裹选区，也可在光标处插入并修改占位文字。支持 **撤销**、**重做**，以及 `Ctrl+Z`、`Ctrl+Shift+Z` / `Ctrl+Y`。

**排版时清理开头 YAML 属性** 仅影响预览和输出，不删除编辑器中的属性，也不写回原稿。正文中的分隔线和段落不会因此被清除。

三个主题均可设置正文 14–20 px 字号、1.5–2.2 倍行距及主题色。**恢复主题默认** 重置这些排版选项；推荐与参考资料区域按正文比例使用略小字号，默认正文 16 px 时约为 14 px。预览、富文本复制和 HTML 导出使用同一渲染结果。

手机、平板和电脑模式内部阅读宽度分别为 390、768、1000 px。画面根据预览栏可用空间自动缩小，完整呈现所选宽度；窄窗口中编辑与预览改为上下排列。缩放只影响界面显示，不写入复制内容或导出 HTML。

开启 **双向同步滚动** 时，两栏按阅读进度近似同步；图片加载、窗口改变和宽度切换会重算。它不是逐段定位，排版结构差异较大时可关闭，分别滚动检查。

## 相关文章推荐

1. 点击 **选择历史文章目录**，确认选中范围。可用 **追加另一个目录** 导入第二个来源，也可 **单独导入 .md / .txt**。
2. 目录入口读取符合规则的 Markdown，排除可识别的 README、隐藏文件和备份等；目录中的文件并不代表已发表，仍需人工核对。单独文件入口可导入 TXT。
3. 在已导入文章中搜索、勾选，再在 **已选文章（按正文顺序）** 中上移、下移或取消。标题优先取开头 YAML 的简单 `title`，其次首个一级标题，最后文件名。
4. 需要短标题时展开 **编辑显示标题**，编辑并离开输入框或按 `Enter`。原始标题和文件名保留；可恢复原题。仅来自文件名且有明确有效日期前缀时提供 **采用建议**，不会自动删去正文标题中的数字。

同内容去重；同名或同标题但不同内容保留为独立文章。重复显示标题给出提示，不自动合并。当前文章末尾生成 **相关文章推荐：** 和可编辑标题列表；渲染时是小标题、每行细分隔。输出只含选中标题，不含历史正文和来源路径，**没有自动添加超链接**，请在公众号编辑器中自行添加。

目录增删或改题后，点击对应来源的 **重新选择更新**，再次选择同一目录。它更新当前快照，不是持续同步。浏览器无法区分磁盘不同位置的同名目录，务必在选择窗口核对；新来源不能用同名目录混入已有来源。

源目录变空时，文件选择器可能不给页面任何文件，页面不能据此判断是否空目录。确认不再需要后用 **移除此来源**；这只移除本地索引，不删除原文件。旧草稿没有来源信息时可重新选择目录按内容绑定，其余未匹配记录手动处理。

生成列表可在正文修改，但再次调整推荐或显示标题会更新可识别的管理范围。若结构修改导致范围无法确认，页面会暂停同步并提示；请检查并手动移除旧列表，再清空选择、重新勾选，避免叠加或误删。

历史正文仅在主动导入时临时读取以提取标题和内容标识，不存入索引或草稿。目录标签、相对路径和标题仍可能包含私人信息，完整草稿请按私密文件保管。

历史导入限制为单文件 2,000,000 字节、一次合计 30,000,000 字节、最多 2000 条记录。读取失败或取消时保留原索引，不把失败当作原文件已删除。

## 参考资料与局部空白清理

可用独立 Markdown 标题，也可用独立粗体段落：

```markdown
**参考资料 / References: **

1. 合成资料名称 — Author A
2. [另一项资料](https://example.com/)

## 下一节
```

识别后的参考区字体稍小，有序列表收紧视觉缩进并保留编号。参考区到下一个章节、独立粗体标题或相关文章区停止；代码、引用和列表中的示例标签不会建立新的参考区。

点击 **清理参考资料行首空白**，只处理识别范围内可安全清理的多余行首空白，不全篇去空格。英文词间空格、链接、代码块及必要列表缩进会保留；嵌套、复杂或不确定结构会保守跳过。四个及以上普通空格或制表符可能代表代码，也会保留。处理作为一次编辑记录，可通过 **撤销** 或 `Ctrl+Z` 恢复。

若留白来自列表样式，程序会在渲染时收紧，不需要删除源码中必要的 Markdown 空格。找不到参考区或没有安全可清理项时，只给提示，不改正文。

## 检查、复制与导出

**发布前排版检查** 提醒缺图、不可读取／歧义图片、尚未填写的组件占位、重复推荐和过长标题。点击结果可定位后修改，修改后重新运行。40 个 Unicode 字符的标题阈值只是窄屏换行建议，不是微信官方规则。检查不会改文，也不阻止复制或导出。

**复制公众号富文本** 尝试写入 HTML 和纯文本；浏览器拒绝或能力不足时会提示，部分浏览器可用选区复制后备方式。请核对实际粘贴结果。**导出含图片 HTML** 将已匹配图片嵌入单个文件，可离线打开，不依赖原附件文件夹。

输出含有你的当前文章和图片。微信可能调整样式或丢弃 Base64 图片，必须检查粘贴后图片、后台保存和手机预览。本工具不登录、不操作或发布公众号。

## 草稿、备份与更新

自动保存和最近 8 份备份位于当前浏览器 IndexedDB，按页面地址的来源隔离。更换浏览器、域名或端口、无痕模式、清理浏览器数据、容量不足，都可能影响草稿。没有直接写回原 Markdown 的保存功能。

**导出完整草稿** 保存当前 Markdown、排版设置、图片、文件索引、相关文章来源和选择顺序；**导入草稿** 可恢复，并保持旧格式兼容。未读取的附件内容和历史正文不打包。完整草稿可能包含私人文件名和目录信息，不要放进公开仓库。

导入的完整草稿文件最多 90,000,000 字节，图片内嵌数据最多 80,000,000 字符；此旧格式校验范围保留以兼容已有草稿，新添图片仍受较小的读取预算约束。草稿备份不要求文章先成功排版，较大旧稿可先原样导出，再缩减正文或图片。

恢复备份会替换当前编辑内容，按确认提示操作。**清除本机草稿** 清除当前来源下的备份，操作前先另存需要的完整草稿。升级程序时建议先导出草稿，停止旧服务，替换完整程序，重启并刷新；升级不自动清空草稿。

## 手动验收

先使用 [合成样例](../samples/使用说明.md)，测试实际图片粘贴、撤销重做、三种宽度与窗口 resize、长短文章滚动、图片加载、富文本粘贴、HTML 离线打开、刷新后草稿及备份恢复。自动化测试不能代替这些浏览器和系统行为检查。公众号后台保存、真实手机预览和实际发布效果另行检查，不需要上传私人文章来验证程序。
